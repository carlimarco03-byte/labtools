Methodology

Reference: SciPy mannwhitneyu()

  • two-sided test;
  • asymptotic normal approximation;
  • average ranks for ties;
  • tie-corrected variance;
  • continuity correction;
  • U statistic = minimum of U1 and U2.

The expected values below were calculated independently using SciPy and are embedded directly in this validation harness.

Therefore the test does not depend on Labistry's normalCDF() for the expected p-values.

Tolerance: ABS_TOL = 1e-10, REL_TOL = 1e-8.

Note: SciPy does not directly return the standardized z statistic. The z values below were independently calculated from the same SciPy-compatible U, tie-corrected variance, and continuity correction.
