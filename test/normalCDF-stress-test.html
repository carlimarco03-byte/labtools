Methodology

The Labistry implementation of normalCDF(x) is tested against independently pre-computed standard normal CDF reference values.

Reference values were calculated using SciPy's high-precision numerical implementation of the standard normal distribution.

The test covers:

  • central region: x ≈ 0;
  • ordinary values: |x| = 0.1 to 5;
  • distribution tails: |x| = 6 to 10;
  • symmetry: Φ(-x) = 1 − Φ(x);
  • NaN and infinite inputs;
  • absolute error;
  • relative error;
  • automatic identification of the worst numerical cases.

Numerical tolerance: ABS_TOL = 1e-10

Relative tolerance: REL_TOL = 1e-8

Warning threshold: ABS_WARN = 1e-7

Failure threshold: ABS_FAIL = 1e-5

Relative error is considered supplementary information in the extreme tails because Φ(x) approaches 0 or 1 and therefore relative error can become numerically misleading.
