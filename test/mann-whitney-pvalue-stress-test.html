Methodology

This harness validates the numerical propagation of the standard normal CDF error into the Mann–Whitney U two-tailed p-value.

The Labistry implementation uses:

p = 2 × (1 − normalCDF(|z|))

The reference p-values are independently precomputed using SciPy's standard normal distribution and are embedded directly in this test. Therefore the reference calculation does not call Labistry's normalCDF().

The dataset tests use the same Mann–Whitney normal approximation with tie correction and continuity correction as the Labistry implementation. This isolates numerical differences in the CDF/p-value calculation rather than comparing different statistical methods.

Primary acceptance criterion: absolute p-value error.

Relative error is reported as a diagnostic metric but is not used as the primary criterion for extremely small tail probabilities, where relative error can become misleading.

This test does not modify any Labistry production function.
